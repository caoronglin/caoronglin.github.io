第7章《卤代烃》

第7章《卤代烃》

📎 第7章 卤代烃.pptx

一、分类与命名

1. 分类

分类依据 类型 实例
卤原子数 一卤、多卤代烃 CH₃Cl (氯甲烷)
烃基结构 伯(1°) / 仲(2°) / 叔(3°)卤代烷 (CH₃)₃CBr (叔丁基溴)
卤原子位置 乙烯型、烯丙基型、苄基型 CH₂=CHCl (氯乙烯)

2. 命名

  • 普通命名法：烃基名 + 卤素名
    例：苄基溴、叔丁基氯。
  • 系统命名法：卤素作取代基，选最长碳链，编号使卤素位次最小。
    例：2-甲基-3,3,5-三氯己烷。
  • 立体标记：含手性碳时用R/S标记（例：(3S,4R)-3-甲基-4-溴己烷）。

二、物理性质

性质 规律
溶解性 不溶于水，溶于有机溶剂（疏水性）
沸点/熔点 > 同碳数烷烃（C-X极性键→分子间力↑）
密度 一氯代烷 <1；多氯代/溴代/碘代烷 >1；RI > RBr > RCl

三、化学性质（核心！）

1. 亲核取代反应（Nucleophilic Substitution）

试剂 (Nu⁻) 产物 应用 反应式
OH⁻ 醇 (ROH) 制备醇 RX + OH⁻ → ROH + X⁻
OR’⁻ 醚 (ROR’) Williamson合成醚 RX + OR’⁻ → ROR’ + X⁻
CN⁻ 腈 (RCN) 增长碳链 RX + CN⁻ → RCN + X⁻
NH₃ 伯胺 (RNH₂) NH₃过量时得伯胺 RX + NH₃ → RNH₂ + HX
I⁻ 碘代烃 (RI) Finkelstein反应（制备RI） RCl + NaI → RI + NaCl

2. 取代机理

机理 特点 底物活性 立体化学
SN₁ 单分子反应，分两步（碳正离子中间体），速率只与[RX]有关 3° > 2° > 1° 外消旋化（±）
SN₂ 双分子反应，一步协同（过渡态），速率与[RX][Nu⁻]有关 CH₃X > 1° > 2° > 3° 构型翻转（Walden转化）

3. 消除反应（Elimination）

  • 产物：烯烃（遵循Zaitsev规则：生成取代基多的稳定烯烃）。
    例：2-溴丁烷 → 2-丁烯（81%）+ 1-丁烯（19%）。

  • 机理：

  • E1：单分子，碳正离子中间体（3°RX易发生）。

  • E2：双分子，一步协同（强碱/高温利于E2）。

  • 竞争关系：

  • 取代 vs 消除：强碱/高温 → 消除；弱碱/低温 → 取代。

  • 叔卤代烷：易消除（空间位阻大）。

4. 与活泼金属反应

  • 格氏试剂（Grignard Reagent）：
    [ \ce{RX + Mg ->[ \text{无水乙醚} ] RMgX} ]

  • 特性：强亲核性，遇H₂O/O₂/CO₂分解 → 需严格无水无氧操作。

  • 应用：合成醇、醛、酮、羧酸等（1912年诺贝尔奖）。

四、卤代烯烃/芳烃的反应活性

类型 结构特点 SN1/SN2活性 原因
烯丙基型 C=C-C-X 或 Ar-CH₂-X 最高 p-π共轭稳定碳正离子/过渡态
孤立型 卤素与双键隔离（≥2C） 中等 无共轭效应
乙烯型 CH₂=CH-X 或 Ar-X 最低 -C效应（卤素孤对电子离域）

五、鉴别与考点

1. 鉴别方法

  • AgNO₃/乙醇溶液：

  • 烯丙基型/苄基型 → 立即沉淀（AgX↓）。

  • 孤立型 → 加热后沉淀。

  • 乙烯型 → 不反应。
    例：鉴别 苄基氯（↓） vs 氯苯（×）。

2. 高频考点

题型 核心内容
反应机理 SN1外消旋化 vs SN2构型翻转；E2反式消除
活性排序 烯丙基溴 > 溴乙烷 > 溴乙烯；RI > RBr > RCl
产物预测 Zaitsev规则应用（例：2-溴-2-甲基丁烷消除→2-甲基-2-丁烯）
合成设计 威廉姆森合成醚；格氏试剂制备及应用
判断题 苄基氯水解为SN1（√）；所有顺式异构体都是Z型（×）

附：典型例题解析
Q：室温下与AgNO₃/乙醇反应最快的是（ ）。
选项：A. 氯苯 B. 氯乙烯 C. 烯丙基氯 D. 1-氯丁烷
A：C（烯丙基型活性最高）。

复习建议：

  1. 对比SN1/SN2和E1/E2的能量曲线图（课件图示）。
  2. 掌握Zaitsev规则的例外（如共轭烯烃优先生成）。
  3. 重点练习格氏试剂的合成应用及注意事项（无水操作）。

信息系统管理工程师 · 备考计划

备考计划

时间坐标

  • 建立本页：2026-09-17
  • 目标考期：2026-10-24 ~ 10-27（2026 年仅此一次）→ 距今 约 37 天
  • ✅ 报名状态：已报名（据用户 2026-09-17 告知）→ 执行 A 方案冲刺，B 方案仅作保底。

战略前提（来自官方与考情，非拍脑袋）

  1. 教材是主线：新版 20 章几乎全新，旧真题覆盖不了 → 先啃《教程（第 2 版）》，真题只作题型与手感训练。
  2. 两科同时及格才算过，成绩不滚动 → 不能押一科放弃一科。
  3. 《应用技术》是真正的门槛：给分靠术语规范与流程完整性，必须动手写、对模板，不能只”看懂”。
  4. 《基础知识》75 题 45 分及格 = 60% 正确率，靠广度覆盖与刷题手感，不靠深挖。

A 方案：冲 2026-10-24（37 天，高强度）

阶段一 · 过书（Day 1–15）

  • 按 [[知识体系]] 的 ①→④ 板块顺序推进；第 1、2 章速览即可（不考案例），把时间喂给 3–16 章。
  • 每章产出：一张思维导图（用 Obsidian 的 Mind Map 插件）+ 5 条自问自答。
  • 达标线：合上书能说出每章”管什么、有哪些过程/角色/文档”。
  • 配套：B 站第 2 版精讲（见 [[复习资料清单]]）按章节倍速过一遍，只补看不懂的。

阶段二 · 刷题 + 案例（Day 16–30）

  • 每天：选择题 60–80 道（信管网题库），错题当场记成笔记，不攒。
  • 隔天：1 道案例题手写，写完对照参考答案标出漏掉的术语与步骤。
  • 重点刷：8.4 运维过程链、15.5 容灾、16.5 等保、10 章项目过程组、9.x 云服务交付。
  • 建立”术语本”：ITIL（事件/问题/变更/配置/发布）、ITSS、SLA、RTO/RPO、等保 2.0 分级、DCMM、DAMA。

阶段三 · 模拟 + 收口（Day 31–37）

  • 全真机考模拟 ≥ 2 次，严格计时，练界面、计算器、草稿纸。
  • 时间分配：选择题 ≤ 60 分钟，案例留足 90 分钟以上。
  • 考前 3 天：不再碰新题，只回顾错题本 + 背诵卡 + 术语本。

案例题答题模板（背下来）

题型 结构
故障排查 定位问题 → 分析日志 → 隔离环境 → 验证修复 → 复盘预防
方案设计 总（目标与依据标准）→ 分（分条列措施，每条挂术语）→ 总（评估与持续改进）
流程设计 按标准框架起手（ITIL/ITSS 过程名）→ 结合场景落地角色与输入输出 → 补应急与改进

得分要点：写术语（ITIL / ITSS / 等保 2.0 / SLA / RTO / RPO / CMDB）、写指标、写责任角色；宁可多分点，不要写大段散文。

B 方案：2027 年长线（已错过报名 / 想稳过）

  • 第 1–2 月：通读教程第 2 版两遍，第一遍建立地图，第二遍做逐章思维导图。
  • 第 3 月：章节题 + 2025 年两场新版真题（信管网回忆版），建立术语本与案例模板。
  • 第 4 月：机考模拟 + 模拟卷，两科轮换保持手感；每周一次限时案例写作。
  • 报名节点：下半年报名约在考前 1–2 个月，提前收藏官网报公告页并设提醒。

待核实事项（考情悬置项）

  • 2026 下半年报名是否已截止 → ✅ 已报名
  • 案例题是否确实考挣值（EVM）计算——机构口径冲突，见 [[考试概览]] 第五节 ✅ 2026-09-18
  • 《基础知识》题量 75 道（多源一致，已基本确认） ✅ 2026-09-18
  • 本地是否有软考相关的落户/补贴政策（考证动机核对） ✅ 2026-09-18

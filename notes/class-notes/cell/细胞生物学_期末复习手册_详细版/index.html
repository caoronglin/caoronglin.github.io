第一章 绪论

一、核心概念

1. 细胞的定义

细胞是由膜包围的含有细胞核（或拟核）的原生质所组成，是生物体结构和功能的基本单位，也是生命活动的基本单位。

2. 细胞生物学

在显微、亚显微和分子水平上，研究细胞生命活动基本规律的基础学科。

二、细胞学说的创立

发展历程

人物 贡献
胡克（Hooke） 发明显微镜，首次观察到细胞壁空腔，提出”cella”
列文虎克（Leeuwenhoek） 用高倍显微镜第一次观察到活细胞
施莱登（Schleiden） 提出植物是由细胞构成的
施旺（Schwann） 提出动物也是由细胞构成的，创立细胞学说
魏尔肖（Virchow） 提出”细胞来自于细胞”

细胞学说的基本原理

  1. 地球上的生物都是由细胞构成的
  2. 所有生活细胞在结构上都是类似的
  3. 所有细胞都来自于已有细胞的分裂，即”细胞来自于细胞”

细胞学说提出的意义

  • 细胞学说、进化论和能量守恒定律被恩格斯称为19世纪的三大发现
  • 将生命带入了微观世界
  • 将动植物统一于细胞

三、细胞是生命活动的基本单位

  1. 一切有机体都由细胞构成——细胞是构成有机体的基本单位
  2. 细胞具有独立的、有序的自控代谢体系——细胞是代谢与功能的基本单位
  3. 细胞是有机体生长与发育的基础
  4. 细胞是遗传的基本单位——细胞具有遗传的全能性

四、细胞的基本共性

  1. 所有细胞表面均有由磷脂双分子层与镶嵌蛋白质构成的生物膜（细胞膜）
  2. 所有细胞都含有两种核酸：DNA与RNA，作为遗传信息复制与转录的载体
  3. 所有细胞都具有蛋白质合成器——核糖体
  4. 所有细胞的增殖都以一分为二的方式进行分裂

五、细胞体积的守恒定律

定义：器官（个体）的大小主要决定于细胞的数量，与细胞的数量成正比，而与细胞的大小无关。

限制细胞大小的因素：

  1. 体积与表面积的关系：细胞必须维持最佳的表面积以适应内外物质交换
  2. 重要分子的有效浓度（上限）：重要的生化反应需要一定的分子浓度
  3. 维持生存所必需物质的足够空间（下限）：必须容纳维持生命活动所需的酶和蛋白质种类

六、巴斯德实验

  • “鹅颈瓶”实验：煮熟的牛肉汤放在鹅颈瓶中，未接触空气的不出现微生物，直接接触空气的密布微生物
  • 意义：否定了”自然发生说”

七、病毒的基本特点

  • 比细胞更小的生命体，无细胞结构，不能独立生存
  • 结构：蛋白质外壳 + 遗传物质（DNA或RNA）
  • 特殊：朊病毒以蛋白质作为遗传物质
  • 病毒是营寄生生活的非细胞生命体，只能在活细胞中进行增殖
  • 病毒以复制方式繁殖，不以分裂方式繁殖（⚠️ 考点）

第二章 细胞的特征与类型

一、细胞的类型及其结构体系

原核细胞

  • 目前发现的最小、最简单的细胞——支原体
  • 支原体是唯一一种没有细胞壁的原核细胞
  • 没有明显的细胞核，无核膜和核仁，只有拟核
  • 区室化不强

真核细胞

  • 包括动物细胞和植物细胞
  • 有明显的细胞核，有核膜和核仁
  • 区室化强

真核细胞的三大基本结构体系

  1. 以脂质及蛋白质成分为基础的生物膜结构系统（膜系统）
  2. 以核酸（DNA或RNA）与蛋白质为主要成分的遗传信息表达系统（遗传信息系统）
  3. 由特异蛋白分子装配构成的细胞骨架系统（骨架系统）

二、原核细胞与真核细胞的比较

相同点

  • 具有类似的细胞质膜结构
  • 以DNA为遗传物质，使用相同的遗传密码
  • 以一分为二的方式进行细胞分裂
  • 具有相同的遗传信息转录和翻译机制，有类似的核糖体结构
  • 代谢机制相同（如糖酵解和TCA循环）
  • 具有相同的化学能贮能机制，如ATP合成酶

不同点（基本特征比较）

特征 原核细胞 真核细胞
细胞核（核膜、核仁等） 无 有
染色体 由一个环状DNA分子构成的单个染色体，DNA不与蛋白质结合 2个以上染色体，染色体由线状DNA与蛋白质组成
细胞内膜系统 无 有（内质网、高尔基体、线粒体、溶酶体等）
核糖体 70S（50S大亚基+30S小亚基） 80S（60S大亚基+40S小亚基）
细胞壁 无（支原体例外） 植物细胞有
细胞骨架 无 有
细胞增殖方式 无丝分裂（直接分裂） 有丝分裂、减数分裂（间接分裂）

遗传结构装置和基因表达的比较

特征 原核细胞 真核细胞
DNA量 少 多
DNA分子数 1 2个以上
DNA分子结构 环状 线状
转录与翻译的时空关系 转录与翻译同时同地进行 核内转录、细胞质内翻译

三、植物细胞与动物细胞的比较

细胞器 植物细胞 动物细胞
细胞壁 有 无
液泡 有 无
叶绿体 有 无
中心体 低等植物有 有

第三章 细胞生物学研究方法

一、显微成像技术

分辨率

  • 定义：能分辨出的相邻两个物点间最小距离的能力。分辨距离越小，分辨率越高。
  • 人眼分辨率：100μm
  • 光学显微镜最大分辨率：0.2μm（200nm）
  • 电子显微镜分辨率：0.1nm

分辨率公式

$$
r = \frac{0.61\lambda}{n\sin\alpha}
$$

波长λ越大，分辨率越小（分辨能力越差）。

电子显微镜与光学显微镜的比较

项目 光学显微镜 电子显微镜
分辨本领 200nm（油镜） 0.1nm
光源 可见光/紫外光 电子束
透镜 玻璃透镜/石英透镜 电磁透镜
真空 不需真空 需真空
原理 利用样品对光的吸收形成明暗反差和颜色变化 利用样品对电子的散射和透射形成明暗反差
样品 样品或切片 超薄切片（50-100nm）

特殊显微镜

  • 激光共聚焦显微镜：能进行”光学切片”（⚠️ 考点）
  • 扫描隧道显微镜：扫描探针对样品表面进行扫描，产生隧道电流，计算机显示
  • 荧光能量共振转移技术（FRET）：成立条件是分子之间的距离小于10nm（⚠️ 考点）

二、细胞工程技术

基本概念

  • 细胞工程：利用细胞生物学的原理和方法，按照人们预先的设计，有计划地改变或创造细胞遗传性的技术
  • 包括：基因工程、染色体工程、染色体组工程、细胞质工程、细胞融合

细胞培养

术语 定义
原代培养 直接从机体取下细胞、组织和器官后立即进行培养
继代培养 通过更换新鲜培养基及不断切割或分离，进行连续多代的培养
细胞系 原代培养物经首次传代成功后即为细胞系
细胞株 从一个经过生物学鉴定的细胞系由单细胞分离培养或通过筛选的方法由单细胞增殖形成的细胞群

细胞融合

  • 自发或人工诱导下，两个或多个细胞融合成一个或多个细胞核的现象
  • 单克隆抗体技术：融合后得到的细胞具有两亲本细胞的特性——既能产生抗体又能无限增殖

流式细胞术

可用于测定：

  • 细胞的大小和特定细胞类群的数量
  • 分选出特定的细胞类群
  • 细胞中DNA、RNA或某种蛋白的含量
  • 以上三种功能都有（⚠️ 考点）

三、其他研究方法

离子交换层析

利用离子交换剂上的可解离基团（活性基团）对各种离子的亲和力不同而达到分离目的。

同位素示踪技术

追踪活细胞中蛋白质合成和分泌过程的方法：

  1. 将放射性同位素标记的氨基酸加到细胞培养基中
  2. 除去培养液并洗涤细胞，换以含未标记氨基酸的培养基
  3. 每隔一定时间取样，利用电镜放射自显影技术探查标记蛋白质的位置

基因与蛋白质的相互推断

从基因推断蛋白质：

基因组DNA分离目的基因 → 以基因组DNA克隆为探针筛选mRNA → 用目的基因的mRNA合成cDNA → 对cDNA测序，推导蛋白质氨基酸序列 → 与其他功能已知的蛋白质比较 → 构建质粒载体进行基因表达

从蛋白质获得基因：

分离蛋白质 → 部分氨基酸测序 → 推导编码基因的部分核酸序列 → 合成放射标记的寡聚核苷酸链作为探针 → 在基因组DNA中筛选 → 分离完整基因并测序

第四章 细胞膜与跨膜运输

一、基本概念区分

术语 定义
细胞膜 细胞膜结构的总称，包括细胞外层的膜和存在于细胞质中的膜
质膜 包围在细胞表面的一层极薄的膜，由膜脂和膜蛋白组成
细胞内膜 细胞器的膜结构
生物膜 细胞内膜和质膜的总称

二、细胞质膜的功能

  1. 界膜和区室化：将细胞与外界环境分隔
  2. 调节运输：控制物质进出
  3. 功能定位与组织化：为酶提供反应场所
  4. 信号检测与传递：接收外界信号
  5. 参与细胞间的相互作用
  6. 能量转换

三、膜的化学组成

膜脂（主要成分）

类型 特点
磷脂 膜脂的基本成分（50%以上），具有一个极性头和两个非极性尾
胆固醇 含量<30%，调节膜的流动性
糖脂 含量<5%，位于质膜外表面

脂质体

根据磷脂分子可在水相中形成稳定的脂双层膜的趋势而制备的人工膜。

膜糖的功能

  1. 提高膜的稳定性
  2. 增强膜蛋白对蛋白酶的抗性
  3. 帮助膜蛋白正确折叠
  4. 参与细胞信号识别和黏着

凝集素

一类能与糖类特异结合的蛋白质，能使细胞发生凝集。

ABO血型决定因子

  • 本质：一种糖脂，其寡糖部分具有决定抗原特异性的作用
  • 区别：血型的主要区别是一种酶
    • A型血：该酶把N-乙酰半乳糖胺加到糖脂抗原上
    • B型血：把半乳糖加到糖脂抗原上
    • AB型血：把N-乙酰半乳糖胺和半乳糖都加到糖脂抗原上
    • O型血：糖脂抗原上无N-乙酰半乳糖胺和半乳糖

四、膜蛋白

三种类型

类型 特点
整合蛋白（内在蛋白） 跨膜蛋白，跨膜部分25-50%是α螺旋，也有β折叠
外周蛋白（附着蛋白） 非共价键连接，直接与脂或与其他蛋白连接
脂锚定蛋白（脂连接蛋白） 共价键与脂连接或通过糖基连接

膜蛋白的功能

  • 运输蛋白：如Na⁺-K⁺泵
  • 连接蛋白：如血影蛋白、肌动蛋白
  • 受体：跨膜，胞外接受信号，胞内传递
  • 酶：如腺苷酸环化酶

膜蛋白的分离方法

  • 去垢剂：一端亲水、一端疏水的两性小分子（如SDS、TritonX-100），是分离与研究膜蛋白的常用试剂
  • 脂质体法：去垢剂溶解膜蛋白 → 分离纯化 → 与磷脂混合 → 透析除掉去垢剂 → 形成脂质体小泡 → 验证功能

五、膜的结构模型——流动镶嵌模型

  1. 膜是由磷脂双分子层构成的
  2. 蛋白质以三种方式与膜结合：镶嵌、嵌入、跨膜

生物膜结构的基本特征

  • 膜的流动性：生物膜的基本特征之一，细胞进行生命活动的必要条件
  • 膜的不对称性

证明膜流动性的实验

  • 人鼠细胞融合实验：抗体标记不同颜色染料，细胞融合后出现不同的颜色混合
  • 荧光漂白恢复技术（FRAP）

证明脂双层的实验

  • Langmuir水盘法：测出脂铺展后的面积与实际测量的红细胞表面积之比约为2:1，提出红细胞的结构是脂双层

六、红细胞膜结构

血影（Ghost）

  • 将红细胞放入低渗溶液中，水进入细胞使红细胞膨胀破裂，释放血红蛋白后质膜重新封闭形成的空壳
  • 是分离红细胞膜蛋白的最好材料
  • 膜骨架：赋予红细胞质膜既有很好的弹性又具有较高强度

七、物质的跨膜运输

膜运输蛋白类型

  • 离子载体：缬氨霉素（特异性运输K⁺）、短杆菌肽A
  • 通道蛋白
  • 载体蛋白

被动运输与主动运输对比

特征 被动运输 主动运输
浓度梯度 顺浓度梯度 逆浓度梯度
能量消耗 不消耗ATP 消耗能量
膜蛋白依赖 不一定 依赖膜蛋白
特异性 简单扩散无特异性 具特异性

被动运输的类型

1. 简单扩散（自由扩散）

  • 限制因素：脂溶性、大小、极性
  • 速度与溶质浓度呈正比

2. 协助扩散（易化扩散）

  • 需膜蛋白帮助
  • 速度快，可达到最大速率
  • 具有特异性，受抑制剂抑制
  • 通道蛋白类型：电压门通道、配体门通道、牵张闸门通道

主动运输

意义：吸收营养，排泄废物，维持离子恒定

能量来源：

  • 直接：如Na⁺/K⁺泵、H⁺泵（ATP直接驱动）
  • 间接：质子或离子浓度梯度

四种类型：

类型 特点 举例
P型泵 需磷酸化 Na⁺/K⁺泵、H⁺泵、Ca²⁺泵
V型泵 位于小泡膜，不需磷酸化 溶酶体膜的H⁺泵
F型质子泵 位于线粒体内膜、植物内囊体膜，不消耗ATP ATP合酶
ABC型质子泵 运输离子、氨基酸、多糖等 细菌质膜、内质网

Na⁺/K⁺泵（P型泵）

  • 每个循环消耗1个ATP，泵出3个Na⁺，泵入2个K⁺
  • 功能：维持渗透压、维持膜电位、驱动协同运输

协同运输

  • 同向协同：小肠上皮细胞吸收葡萄糖通过Na⁺协同运输实现（⚠️ 考点）
  • 反向协同：如Na⁺/Ca²⁺交换

受体介导的胞吞作用

  • 细胞摄入LDL颗粒的过程是受体介导的胞吞作用（⚠️ 考点）
  • 过程：配体与受体结合 → 有被小窝 → 有被小泡 → 脱包被 → 胞内体 → 分选

第五章 细胞质基质与内膜系统

一、细胞质基质

定义

在真核细胞的细胞质中，除去可分辨的细胞器以外的胶状物质，占据着细胞膜内、细胞核外的细胞内空间。

特点

  1. 细胞质基质是高度有序的体系
  2. 细胞质骨架纤维贯穿其中，多数蛋白质直接或间接与骨架结合
  3. 蛋白质之间、蛋白质与其他分子之间存在多种相互作用
  4. 多数中间代谢在细胞质基质中进行
  5. 蛋白质的修饰、蛋白质的选择性降解等都在细胞质基质中进行

功能

  • 进行中间代谢反应
  • 蛋白质的合成与修饰（如N端甲基化、乙酰化等）
  • 蛋白质的泛素化降解途径
  • 维持细胞内环境

二、内膜系统

定义

细胞质中在结构、功能及发生上相互密切关联的膜性细胞器的总称。

组成

  • 内质网（ER）
  • 高尔基体（Golgi）
  • 溶酶体（Lysosome）
  • 分泌泡
  • 核膜

⚠️ 线粒体不属于内膜系统（虽然也是膜性细胞器）

三、内质网（ER）

两种类型

类型 特点 功能
糙面内质网（RER） 表面有核糖体附着，多为扁囊状 分泌蛋白、膜蛋白合成
光面内质网（SER） 表面无核糖体，多为管状 脂类合成、Ca²⁺储存、解毒

信号假说（分泌蛋白合成机制）

  1. 信号肽在游离核糖体上合成
  2. **信号识别颗粒（SRP）**识别信号肽，使翻译暂停
  3. SRP-核糖体复合体与内质网膜上的SRP受体结合
  4. 核糖体与易位子结合，SRP释放
  5. 肽链通过易位子进入内质网腔
  6. 信号肽被信号肽酶切除
  7. 肽链继续延伸并折叠

指导分泌性蛋白在RER上合成的决定因素

  • 信号肽
  • 信号识别颗粒（SRP）
  • 信号识别颗粒受体（SRP受体）
  • 以上均包括（⚠️ 考点）

四、高尔基体

结构

  • 顺面（cis面）：面向内质网，接收来自内质网的囊泡
  • 中间膜囊
  • 反面（trans面）：面向质膜，分泌囊泡

功能

  1. 蛋白质的糖基化修饰（O-连接糖基化）
  2. 蛋白质的分选与运输
  3. 溶酶体酶的标记（M6P）
  4. 合成多糖（植物细胞）

五、溶酶体

定义

单层膜包被的囊状结构，内含多种酸性水解酶，是细胞内的消化器官。

溶酶体酶的特点

  • 最适pH约5.0（酸性环境）
  • 标志酶：酸性磷酸酶
  • 溶酶体酶之所以能选择性地运入溶酶体是因为它们具有M6P标志（⚠️ 考点）

溶酶体的发生过程

  1. 溶酶体酶在糙面内质网上合成
  2. 进入内质网腔，转运至高尔基体
  3. 在高尔基体顺面膜囊中，溶酶体酶被标记上甘露糖-6-磷酸（M6P）
  4. 在反面膜囊中，M6P受体识别并结合带有M6P标志的酶
  5. 通过网格蛋白包被的囊泡出芽，形成运输囊泡
  6. 运输囊泡与晚期胞内体融合
  7. 在酸性环境中，M6P受体与酶解离，受体返回高尔基体
  8. 晚期胞内体成熟为溶酶体

溶酶体的功能

  • 细胞内消化
  • 自噬作用
  • 自溶作用
  • 细胞外消化

台-萨氏症（Tay-Sachs disease）

由于溶酶体功能紊乱导致（⚠️ 考点）

六、微粒体

在细胞匀浆和差速离心过程中，由破碎的内质网自我融合形成的近似球形的囊泡结构。

七、过氧化物酶体

  • 以分裂方式增殖（⚠️ 考点）
  • 含氧化酶和过氧化氢酶
  • 功能：脂肪酸的β-氧化、解毒

八、COP包被膜泡

类型 运输方向
COPⅠ 高尔基体 → 内质网（逆向运输）（⚠️ 考点）
COPⅡ 内质网 → 高尔基体（顺向运输）
网格蛋白 质膜 → 胞内体；高尔基体 → 溶酶体

第六章 细胞能量转换——线粒体和叶绿体

一、线粒体

结构

  • 外膜：通透性较高
  • 内膜：向内折叠形成嵴，通透性很低
  • 膜间隙：内外膜之间的空间
  • 基质：含三羧酸循环酶系、DNA、核糖体

半自主性细胞器

  • 含有自身的DNA和核糖体
  • 能合成部分蛋白质，但大部分蛋白质由核基因编码

功能

  • 氧化磷酸化
  • ATP合成
  • 三羧酸循环
  • 脂肪酸氧化

二、叶绿体

结构

  • 外膜和内膜
  • 基质（stroma）
  • 类囊体：扁平囊状结构，堆叠形成基粒

光合作用

  • 光反应：在类囊体膜上进行
  • 暗反应（卡尔文循环）：在基质中进行

三、线粒体与叶绿体的比较

特征 线粒体 叶绿体
分布 动植物细胞 植物细胞
内膜折叠 嵴 类囊体
功能 氧化磷酸化 光合磷酸化
电子传递 呼吸链 光合链
ATP合酶位置 内膜 类囊体膜

四、化学渗透假说

  • 电子传递过程中释放的能量将质子（H⁺）从基质泵入膜间隙
  • 形成跨膜的质子电化学梯度
  • 质子通过ATP合酶回流时驱动ATP合成

第七章 细胞骨架

一、概述

细胞骨架是由蛋白质纤维组成的网状结构体系，包括：

  • 微丝（Microfilament, MF）
  • 微管（Microtubule, MT）
  • 中间纤维（Intermediate Filament, IF）

二、微丝（MF）

基本结构

  • 由**肌动蛋白（Actin）**组成
  • 直径约7nm
  • 具有极性：正端（+）和负端（-）

组装与去组装

  • 踏车行为：正端组装速度 = 负端去组装速度，微丝长度不变
  • 鬼笔环肽：与微丝特异结合，抑制微丝解聚（⚠️ 考点）
  • 细胞松弛素：抑制微丝聚合

微丝结合蛋白

  • 肌球蛋白（Myosin）
  • 原肌球蛋白（Tropomyosin）
  • 肌钙蛋白（Troponin）

肌肉收缩机制——肌丝滑动模型

  • 肌收缩时，肌节变短（⚠️ 考点）
  • 肌动蛋白纤维和肌球蛋白纤维本身不收缩，而是相对滑动
  • Z带之间的距离缩短

微丝的功能

  • 肌肉收缩
  • 细胞运动（伪足、微绒毛）
  • 胞质分裂（收缩环）
  • 维持细胞形态
  • 细胞连接（黏着带、黏着斑）

三、微管（MT）

基本结构

  • 由α-微管蛋白和β-微管蛋白组成的异二聚体
  • 直径约25nm
  • 13条原纤维围成中空管状结构
  • 具有极性：正端（+）和负端（-）

微管组织中心（MTOC）

  • 中心体是动物细胞的主要MTOC
  • γ-微管蛋白存在于中心体外周物质中（⚠️ 考点）

微管特异性药物

药物 作用
秋水仙碱（Colchicine） 抑制微管聚合
长春花碱（Vinblastine） 抑制微管聚合
紫杉醇（Taxol） 抑制微管解聚，稳定微管（⚠️ 考点）

微管的功能

  • 维持细胞形态
  • 细胞内运输（驱动蛋白向+端、动力蛋白向-端）
  • 细胞分裂（纺锤体）
  • 纤毛和鞭毛的运动

微管马达蛋白

  • 驱动蛋白（Kinesin）：向微管正端（+）运输
  • 动力蛋白（Dynein）：向微管负端（-）运输

四、中间纤维（IF）

基本结构

  • 直径约10nm（介于微丝和微管之间）
  • 没有极性（⚠️ 考点：下列结构没有极性的是——中间纤维）
  • 组装不需要ATP或GTP

类型

类型 分布 蛋白
Ⅰ型 酸性角蛋白 上皮细胞
Ⅱ型 碱性角蛋白 上皮细胞
Ⅲ型 波形蛋白、结蛋白 间充质细胞、肌细胞
Ⅳ型 神经丝蛋白 神经元
Ⅴ型 核纤层蛋白 细胞核

功能

  • 机械支撑
  • 细胞连接（桥粒、半桥粒）（⚠️ 考点）
  • 维持细胞核形态（核纤层）

五、三种细胞骨架的比较

特征 微丝 微管 中间纤维
直径 7nm 25nm 10nm
基本蛋白 肌动蛋白 α/β-微管蛋白 多种
极性 有 有 无
核苷酸 ATP GTP 不需要
特异性药物 鬼笔环肽、细胞松弛素 秋水仙碱、紫杉醇 无

六、细胞连接与细胞骨架

  • 黏着带：微丝 → 细胞间连接
  • 黏着斑：微丝 → 细胞与基质连接（体外培养成纤维细胞通过黏着斑附着）
  • 桥粒：中间纤维 → 细胞间连接（可将整个组织的细胞连成整体）
  • 半桥粒：中间纤维 → 细胞与基质连接

第八章 核糖体

一、基本结构

  • 由rRNA和蛋白质组成
  • 大小两个亚基

原核与真核核糖体比较

特征 原核细胞 真核细胞
核糖体 70S 80S
大亚基 50S 60S
小亚基 30S 40S

二、核糖体的功能

  • 蛋白质合成的场所
  • 原核细胞与真核细胞都具有的细胞器（⚠️ 考点）

三、蛋白质合成过程

  1. 起始：小亚基与mRNA结合，起始tRNA识别起始密码子AUG
  2. 延伸：大亚基结合，肽键形成，核糖体沿mRNA移动
  3. 终止：遇到终止密码子，释放因子结合，肽链释放

第九章 细胞核

一、核被膜

结构

  • 外核膜：与糙面内质网相连，表面有核糖体
  • 内核膜：与核纤层相连
  • 核周隙：内外核膜之间的空间
  • 核孔复合体（NPC）：核质之间物质运输的通道

二、核孔复合体

功能

  • 被动扩散：小分子（<5000Da）自由通过
  • 主动运输：大分子需信号介导

亲核蛋白

  • 在细胞质中合成后需要进入细胞核发挥功能的蛋白质
  • 含有核定位信号（NLS）
  • 通过核孔复合体主动运输进入细胞核

三、染色质与染色体

染色质类型

类型 特点
常染色质 松散，转录活跃
异染色质 紧密，转录不活跃

⚠️ 完整的间期细胞核中看不到染色体（考点）

染色体的结构层次

DNA → 核小体（串珠状）→ 30nm纤维 → 环状结构域 → 染色体

核小体

  • 染色质的基本结构单位
  • 由组蛋白八聚体（H2A、H2B、H3、H4各两个）+ 约146bp DNA组成
  • H1组蛋白位于核小体连接处

四、核仁

结构

  • 纤维中心
  • 致密纤维组分
  • 颗粒组分

功能

  • rRNA的合成（转录）
  • 核糖体亚基的组装

五、核基质（核骨架）

  • 细胞核内的纤维蛋白网络
  • 维持细胞核的形态结构
  • 参与DNA复制和基因表达

第十二章 细胞信号转导

一、基本概念

信号分子类型

类型 特点 举例
激素 远距离作用 胰岛素、甲状腺素
局部介质 短距离作用 生长因子、NO
神经递质 突触传递 乙酰胆碱

受体类型

类型 特点
细胞内受体 脂溶性信号分子（如类固醇激素）
细胞表面受体 水溶性信号分子

细胞表面受体的三种类型

  1. 离子通道偶联受体
  2. G蛋白偶联受体（GPCR）
  3. 酶联受体（如受体酪氨酸激酶RTK）

二、第二信使

定义

细胞外信号分子（第一信使）与受体结合后，在细胞内产生的、能传递信号的小分子物质。

常见第二信使

第二信使 来源
cAMP ATP经腺苷酸环化酶（AC）催化
cGMP GTP经鸟苷酸环化酶（GC）催化
Ca²⁺ 内质网释放或胞外流入
IP₃（三磷酸肌醇） PIP₂经PLC水解
DAG（二酰甘油） PIP₂经PLC水解

⚠️ 鸟苷酸环化酶不是第二信使，它是合成cGMP的酶（考点）

三、G蛋白偶联受体（GPCR）信号通路

GPCR结构

  • 7次跨膜蛋白
  • N端在胞外，C端在胞内

G蛋白

  • 三聚体G蛋白：α、β、γ三个亚基
  • α亚基结合GTP时活化，结合GDP时失活
  • 具有GTP酶活性

cAMP-PKA信号通路

  1. 信号分子与GPCR结合
  2. GPCR活化G蛋白（Gs）
  3. Gs活化腺苷酸环化酶（AC）
  4. AC催化ATP → cAMP
  5. cAMP活化蛋白激酶A（PKA）
  6. PKA磷酸化靶蛋白

⚠️ 动物细胞中cAMP的主要生物学功能是活化蛋白激酶A（考点）

磷脂酰肌醇信号通路

  1. 信号分子与GPCR结合
  2. GPCR活化G蛋白（Gq）
  3. Gq活化磷脂酶C（PLC）
  4. PLC水解PIP₂ → IP₃ + DAG
  5. IP₃促使内质网释放Ca²⁺
  6. DAG活化蛋白激酶C（PKC）

四、受体酪氨酸激酶（RTK）信号通路

特点

  • 胞外有配体结合域
  • 胞内有酪氨酸激酶结构域
  • 配体结合后发生二聚化和自磷酸化

Ras-MAPK通路

  1. 生长因子（如EGF）与RTK结合 → 二聚化、自磷酸化
  2. 接头蛋白Grb2结合磷酸化RTK
  3. Sos（Ras-GEF）活化Ras（Ras-GDP → Ras-GTP）
  4. Ras活化Raf（MAPKKK）
  5. Raf → MEK（MAPKK）→ ERK（MAPK）
  6. ERK进入细胞核，磷酸化转录因子

⚠️ EGF的跨膜信号转导通过活化酪氨酸激酶实现（考点）

五、气体信号分子

气体 功能
NO 与血压调控直接有关（⚠️ 考点），舒张血管
CO 神经递质
H₂S 信号分子

NO的作用机制：活化鸟苷酸环化酶 → cGMP → 血管舒张

六、分子开关

定义

在细胞内信号传递过程中，能在活化状态和非活化状态之间转换的蛋白质。

类型

类型 活化形式 失活形式 调节因子
G蛋白 GTP结合 GDP结合 GEF（活化）、GAP（失活）
蛋白激酶/磷酸酶 磷酸化 去磷酸化 激酶/磷酸酶

第十三章 细胞分裂与增殖调控

一、细胞周期

分期

  • 间期：G₁期 → S期 → G₂期
  • 分裂期（M期）：前期 → 前中期 → 中期 → 后期 → 末期 → 胞质分裂

各期特点

时期 主要事件
G₁期 RNA和蛋白质合成，细胞生长
S期 DNA复制，组蛋白合成
G₂期 继续生长，合成M期所需蛋白
M期 染色体分离，细胞分裂

⚠️ 高等生物体细胞，细胞周期时间长短差别主要与G₁期相关（考点）

二、有丝分裂

前期

  • 染色质凝缩为染色体
  • 核仁解体
  • 中心体分开，移向两极

前中期

  • 核膜破裂
  • 纺锤体微管与染色体动粒结合

中期

  • 染色体排列在赤道板上
  • 纺锤体完全形成

后期

  • 姐妹染色单体分开
  • 分别移向两极

末期

  • 染色体去凝缩
  • 核膜重新形成
  • 核仁出现

三、MPF（卵细胞成熟促进因子）

组成

  • CDK1（Cdc2）：催化亚基
  • Cyclin B：调节亚基

功能

  • 调控G₂期向M期转换（⚠️ 考点）

四、细胞周期调控

细胞周期蛋白（Cyclin）

  • 含量随细胞周期波动
  • 与CDK结合形成活性复合物

周期蛋白依赖性激酶（CDK）

  • 含量相对恒定
  • 需与Cyclin结合才具活性

检验点

检验点 检查内容
G₁/S检验点 环境条件、DNA损伤
G₂/M检验点 DNA复制完成、DNA损伤
M期检验点 染色体与纺锤体连接

第十四章 细胞分化与干细胞

一、细胞分化

定义

在个体发育中，由一种相同的细胞类型经细胞分裂后逐渐在形态、结构和功能上形成稳定性差异，产生不同细胞类群的过程。

特点

  • 稳定性
  • 基因表达的时空特异性
  • 细胞的全能性：细胞经分裂和分化后仍具有产生完整有机体的潜能或特性

二、干细胞

分类

类型 分化潜能 举例
全能干细胞 可发育为完整个体 受精卵
多能干细胞 可分化为多种细胞 胚胎干细胞
专能干细胞 分化为特定类型细胞 造血干细胞

第十五章 细胞衰老与细胞程序性死亡

一、细胞衰老

Hayflick界限

体外培养的细胞分裂次数是有限的，正常人体细胞约分裂50-60次。

端粒与衰老

  • 端粒随每次分裂缩短
  • 端粒缩短到一定程度触发衰老

二、细胞凋亡

定义

由基因控制的细胞自主的有序的死亡。

与坏死的区别

特征 凋亡 坏死
诱因 生理或病理 病理
细胞形态 皱缩、出泡 肿胀、破裂
膜完整性 保持 破裂
炎症反应 无 有
DNA降解 梯状条带 弥散

凋亡途径

  1. 线粒体途径（内源途径）：细胞色素c释放 → Caspase-9活化
  2. 死亡受体途径（外源途径）：Fas/FasL → Caspase-8活化

三、简答题（每题5分，共25分）

1. 细胞内的蛋白降解机制有哪些？试举例说明蛋白降解的作用或意义。

答：

  • 泛素-蛋白酶体途径：泛素标记靶蛋白 → 26S蛋白酶体识别并降解。如细胞周期蛋白的周期性降解调控细胞周期进程。
  • 溶酶体途径：通过自噬将蛋白质运至溶酶体降解。如细胞在饥饿状态下通过自噬降解蛋白质提供能量。

2. 简述膜蛋白的三种类型及其分离方法。

答：

三种类型：

  • 整合蛋白（内在蛋白）：跨膜蛋白，跨膜部分多为α螺旋或β折叠
  • 外周蛋白（附着蛋白）：通过非共价键与膜脂或膜蛋白连接
  • 脂锚定蛋白（脂连接蛋白）：通过共价键与脂分子连接

分离方法：使用去垢剂（如SDS、TritonX-100）溶解膜蛋白 → 分离纯化 → 与磷脂混合 → 透析除去去垢剂 → 形成脂质体小泡 → 验证功能。

3. 何为蛋白质分选？细胞内蛋白质分选的基本途径、分选类型是怎样的？

答：

蛋白质分选是指蛋白质在细胞质基质中合成后，被准确运送到细胞各部位的过程。

基本途径：

  • 翻译后转运：蛋白质完全合成后再转运（线粒体、叶绿体、过氧化物酶体、细胞核）
  • 共翻译转运：合成与转运同时进行（内质网）

分选类型：

  • 门控运输：通过核孔复合体（如亲核蛋白入核）
  • 跨膜运输：穿过膜结构（如线粒体蛋白）
  • 囊泡运输：囊泡出芽和融合（如内质网→高尔基体→质膜）

4. 简述细胞质基质的特点。

答：

  • 细胞质基质是高度有序的体系
  • 细胞质骨架纤维贯穿其中，多数蛋白质直接或间接与骨架结合
  • 蛋白质之间、蛋白质与其他分子之间存在多种相互作用
  • 多数中间代谢在细胞质基质中进行
  • 蛋白质的修饰（如N端甲基化、乙酰化）、蛋白质的选择性降解（泛素-蛋白酶体途径）都在细胞质基质中进行

5. 试述溶酶体的发生过程。

答：

  1. 溶酶体酶在糙面内质网上合成
  2. 进入内质网腔，转运至高尔基体
  3. 在高尔基体顺面膜囊中，溶酶体酶被标记上甘露糖-6-磷酸（M6P）
  4. 在反面膜囊中，M6P受体识别并结合带有M6P标志的酶
  5. 通过网格蛋白包被的囊泡出芽，形成运输囊泡
  6. 运输囊泡与晚期胞内体融合
  7. 在酸性环境中，M6P受体与酶解离，受体返回高尔基体
  8. 晚期胞内体成熟为溶酶体

四、论述题（共25分）

1. 试述G蛋白偶联受体结构、功能、及其信号传导机制。（10分）

答：

结构：

  • GPCR是7次跨膜蛋白，N端在胞外，C端在胞内
  • 胞外部分负责与信号分子（配体）结合
  • 胞内部分与三聚体G蛋白相互作用

功能：

  • 接收细胞外信号（激素、神经递质、光、气味等）
  • 将信号传递到细胞内，引发级联反应

信号传导机制（以cAMP-PKA通路为例）：

  1. 信号分子（第一信使）与GPCR结合，引起受体构象变化
  2. 活化的GPCR催化G蛋白α亚基上GDP与GTP交换，G蛋白活化
  3. α亚基与βγ亚基解离，α-GTP活化腺苷酸环化酶（AC）
  4. AC催化ATP → cAMP（第二信使）
  5. cAMP活化蛋白激酶A（PKA）
  6. PKA磷酸化下游靶蛋白，产生细胞应答
  7. α亚基的GTP酶活性水解GTP → GDP，α亚基与βγ重新结合，信号终止

此外还有磷脂酰肌醇通路：Gq活化PLC → PIP₂水解为IP₃和DAG → IP₃释放Ca²⁺，DAG活化PKC。

2. 某研究者发现了一个具有GARP结构域的蛋白GLKx，初步判定该蛋白是一个转录因子。请设计实验方案以深入解析该蛋白的生物学功能。（15分）

答：

（1）确定该蛋白的亚细胞定位：

  • 构建GLKx-GFP融合蛋白表达载体
  • 转化植物细胞（农杆菌介导或基因枪法）
  • 激光共聚焦显微镜观察GFP荧光信号在细胞中的分布
  • 可用DAPI染色标记细胞核，观察GFP与DAPI是否共定位
  • 若定位于细胞核，进一步支持其为转录因子的判断

（2）证明该蛋白的转录激活活性：

  • 构建GAL4 DNA结合域（BD）-GLKx融合蛋白表达载体
  • 共转化含有GAL4结合位点的报告基因载体（如GAL4-UAS::GUS/Luciferase）
  • 在酵母双杂交系统或植物原生质体中检测报告基因的表达
  • 若报告基因表达显著高于对照，说明GLKx具有转录激活活性

（3）寻找该蛋白的靶基因并加以验证：

  • ChIP-seq：用GLKx特异性抗体进行染色质免疫共沉淀，结合高通量测序，在全基因组范围鉴定GLKx结合的DNA序列
  • RNA-seq：比较野生型和glkx突变体（或过表达株系）在低磷条件下的转录组差异
  • 整合ChIP-seq和RNA-seq数据，筛选直接靶基因
  • 验证手段：
    • EMSA（电泳迁移率变动分析）：体外验证GLKx与靶基因启动子的结合
    • 双荧光素酶报告系统：在植物原生质体中验证GLKx对靶基因启动子的调控
    • qRT-PCR：验证靶基因在突变体和过表达株系中的表达变化

（4）阐明该蛋白在植物低磷胁迫中的功能及可能涉及的生物学过程：

  • 构建glkx敲除突变体和GLKx过表达株系
  • 在不同磷浓度条件下进行表型分析：
    • 测定根长、根毛密度、鲜重等生长指标
    • 测定植株磷含量和磷吸收效率
    • 检测磷转运蛋白基因的表达变化
  • 分析GLKx可能参与的生物学过程：
    • 磷饥饿响应信号通路
    • 根系构型调控
    • 磷转运和再分配
    • 脂质代谢重塑（磷缺乏时膜脂由磷脂转为糖脂/硫脂）
  • 通过转录组和代谢组分析，系统阐明GLKx调控的低磷应答网络

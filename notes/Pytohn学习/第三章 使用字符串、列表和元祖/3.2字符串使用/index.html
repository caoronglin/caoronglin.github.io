3.2字符串使用

一、什么是字符串

在Python中，字符串是基本数据类型，是一个不可变的字符序列，用于存储和表示基本的文本信息。也是一种基本的信息表示方式。

字符串的定义方式

Python中可以使用以下三种方式定义字符串：

  1. 单引号：'hello'
  2. 双引号："hello"
  3. 三引号：'''hello''' 或 """hello"""
  4. 长字符串：用连续的三个引号连接，支持跨行
  5. 原始字符串：在一个字符串前加 rr'hello\worrd'其中的 \ 不转义，直接输出

字符串的特点

  1. 不可变性：字符串一旦创建就不能更改
  2. 序列性：字符串是字符的有序序列
  3. 驻留机制：Python对相同的字符串只保留一份拷贝，节省内存空间

常见问题

split()

在 Python 中，split() 和 split(" ") 的区别主要在于 分隔符的处理方式，尤其是对空白字符的处理逻辑。以下是详细对比：

1. split()（不带参数）

  • 默认行为：
    按 任意数量的空白字符（如空格、换行符、制表符 \t 等）作为分隔符。

  • 特点：

  • 会自动忽略 开头和结尾的空白。

  • 多个连续的空白字符（如 " ", "\t\t"）会被视为一个分隔符。

  • 如果字符串全由空白组成（如 " "），split() 会返回一个空列表 []。

  • 示例：

2. split(" ")（带空格参数）

  • 默认行为：
    仅以 单个空格 作为分隔符。

  • 特点：

  • 不会自动忽略多个连续空格，多个空格会被拆分为多个分隔符。

  • 会导致结果中出现 空字符串（""）。

  • 如果字符串全由空格组成（如 " "），split(" ") 会返回 ['', '', '', '']。

  • 示例：

核心区别总结

特性 split() split(" ")
分隔符类型 任意空白字符（空格、换行、制表符等） 仅单个空格
多个连续空格处理 合并为一个分隔符 拆分为多个分隔符
开头/结尾空白处理 自动忽略 保留为空字符串
全空白字符串处理 返回空列表 [] 返回多个空字符串（如 ['', '', '']）
适用场景 通用字符串分割（如统计单词数量） 严格按空格分割（如需要保留空格信息）

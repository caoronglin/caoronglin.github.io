以下是针对“全国计算机等级考试二级Python语言程序设计”常用函数的系统总结，依据最新考试大纲和高频考点整理，分类清晰，便于复习和速查。

计算机二级Python常用函数总结

一、基本输入输出函数

函数 说明 示例
input() 从键盘获取用户输入，返回字符串 name = input("请输入姓名：")
print() 向屏幕输出信息 print("Hello", name)
eval() 执行字符串表达式，返回结果 result = eval("1 + 2")

二、数据类型转换函数

函数 说明 示例
int() 转换为整数 int("3") → 3
float() 转换为浮点数 float("3.14") → 3.14
str() 转换为字符串 str(123) → “123”
list() 转换为列表 list("abc") → [‘a’,’b’,’c’]
tuple() 转换为元组 tuple([1,2,3]) → (1,2,3)
set() 转换为集合 set("abac") → {‘a’,’b’,’c’}
dict() 创建字典 dict(a=1,b=2) → {‘a’:1,’b’:2}
ord() 字符转ASCII码 ord('A') → 65
chr() ASCII码转字符 chr(65) → ‘A’
bin() 整数转二进制字符串 bin(10) → ‘0b1010’
oct() 整数转八进制字符串 oct(10) → ‘0o12’
hex() 整数转十六进制字符串 hex(10) → ‘0xa’

三、常用内置函数

函数 说明 示例
len() 返回对象长度 len("abc") → 3
max() 返回最大值 max([1,2,3]) → 3
min() 返回最小值 min([1,2,3]) → 1
sum() 求和 sum([1,2,3]) → 6
abs() 绝对值 abs(-5) → 5
pow() 幂运算 pow(2,3) → 8
round() 四舍五入 round(3.1415,2) → 3.14
range() 生成整数序列 list(range(3)) → [0,1,2]
type() 返回对象类型 type(123) → <class ‘int’>
isinstance() 判断对象是否为指定类型 isinstance(123, int) → True

四、序列操作函数（字符串、列表、元组）

函数/方法 说明 示例
str.split() 分割字符串 "a,b".split(',') → [‘a’,’b’]
str.join() 连接序列为字符串 ','.join(['a','b']) → “a,b”
str.replace() 替换字符串 "abc".replace('a','A') → “Abc”
str.strip() 去除首尾指定字符 " abc ".strip() → “abc”
str.upper() 转大写 "abc".upper() → “ABC”
str.lower() 转小写 "ABC".lower() → “abc”
list.append() 列表末尾添加元素 [1,2].append(3) → [1,2,3]
list.insert() 指定位置插入元素 [1,3].insert(1,2) → [1,2,3]
list.remove() 移除指定元素 [1,2,3].remove(2) → [1,3]
list.pop() 弹出指定位置元素 [1,2,3].pop(1) → 2
list.sort() 列表排序 [3,1,2].sort() → [1,2,3]
list.reverse() 列表反转 [1,2,3].reverse() → [3,2,1]
list.index() 返回元素索引 [1,2,3].index(2) → 1
list.count() 统计元素出现次数 [1,2,2,3].count(2) → 2

五、字典操作函数

函数/方法 说明 示例
dict.keys() 返回所有键 list({'a':1}.keys()) → [‘a’]
dict.values() 返回所有值 list({'a':1}.values()) → [1]
dict.items() 返回所有键值对 list({'a':1}.items()) → [(‘a’,1)]
dict.get() 获取指定键的值 {'a':1}.get('a',0) → 1
dict.pop() 弹出指定键值对 {'a':1}.pop('a') → 1
dict.update() 更新字典 {'a':1}.update({'b':2}) → {‘a’:1,’b’:2}
dict.clear() 清空字典 {'a':1}.clear() → {}

六、集合操作函数

函数/方法 说明 示例
set.add() 添加元素 {1}.add(2) → {1,2}
set.remove() 移除元素 {1,2}.remove(1) → {2}
set.union() 并集 {1,2}.union({2,3}) → {1,2,3}
set.intersection() 交集 {1,2}.intersection({2,3}) → {2}
set.difference() 差集 {1,2}.difference({2,3}) → {1}

七、文件操作函数

函数/方法 说明 示例
open() 打开文件 f = open("test.txt", "r")
f.read() 读取全部内容 f.read()
f.readline() 读取一行 f.readline()
f.readlines() 读取所有行 f.readlines()
f.write() 写入字符串 f.write("Hello")
f.writelines() 写入多行 f.writelines(["a\n","b\n"])
f.seek() 移动文件指针 f.seek(0)
f.close() 关闭文件 f.close()
with open() 自动关闭文件 with open("test.txt") as f: ...

八、常用标准库函数

1. turtle库（绘图）

函数/方法 说明 示例
turtle.setup() 设置画布大小和位置 turtle.setup(800,600)
turtle.penup() 提笔 turtle.penup()
turtle.pendown() 落笔 turtle.pendown()
turtle.pensize() 设置画笔宽度 turtle.pensize(5)
turtle.pencolor() 设置画笔颜色 turtle.pencolor("red")
turtle.forward() 前进 turtle.forward(100)
turtle.backward() 后退 turtle.backward(50)
turtle.right() 右转 turtle.right(90)
turtle.left() 左转 turtle.left(90)
turtle.circle() 画圆 turtle.circle(50)
turtle.goto() 移动到指定坐标 turtle.goto(100,100)
turtle.done() 结束绘图 turtle.done()

2. random库（随机数）

函数/方法 说明 示例
random.seed() 设置随机种子 random.seed(6)
random.random() 生成[0,1)随机浮点数 random.random()
random.randint() 生成随机整数 random.randint(1,100)
random.uniform() 生成随机浮点数 random.uniform(1,10)
random.choice() 随机选择元素 random.choice([1,2,3])
random.shuffle() 随机打乱序列 random.shuffle([1,2,3])

3. time库（时间）

函数/方法 说明 示例
time.time() 获取当前时间戳 time.time()
time.ctime() 转换为可读字符串 time.ctime(time.time())
time.sleep() 程序休眠（秒） time.sleep(1)

九、常用第三方库函数

1. jieba库（中文分词）

函数/方法 说明 示例
jieba.cut() 精确/全模式分词 list(jieba.cut("我爱Python"))
jieba.lcut() 返回列表分词 jieba.lcut("我爱Python")

2. PyInstaller库（打包）

命令/函数 说明 示例
pyinstaller -F 打包为单个可执行文件 pyinstaller -F test.py

十、格式化输出

方法 说明 示例
str.format() 字符串格式化 "{} {}".format("Hello", "World")
f"{}" f-string格式化（Python 3.6+） f"Hello {name}"

十一、异常处理

语句 说明 示例
try-except 捕获异常 try: ... except: ...
try-finally 无论是否异常都执行 try: ... finally: ...

十二、常用操作技巧

  • 列表推导式：[x*x for x in range(5)] → [0,1,4,9,16]
  • 字典推导式：{x:x*x for x in range(3)} → {0:0,1:1,2:4}
  • 条件表达式：x if x>0 else -x

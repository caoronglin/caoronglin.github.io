一、三种基本程序结构

1. 顺序结构

  • 特点：语句按顺序依次执行
  • 易错点：忽略输入数据的合法性检查（如三角形三边值检查）

2. 选择结构

  • 二分支：if-else语句
  • 多分支：switch语句或if-else if-else结构
  • 特点：根据条件选择执行路径

3. 循环结构

  • 当型循环：while, for
  • 直到型循环：do-while
  • 特点：重复执行代码块直到条件不满足

五、易错点总结

  1. 选择结构：
  • if条件后误加分号：if(x>0); { ... }
  • 混淆=和==：if(x=0) 总是假
  • switch中忘记break导致case穿透
  1. 循环结构：
  • 死循环：循环条件永远成立
  • 循环变量未初始化
  • 循环嵌套时内外层变量混淆
  • 在for循环中修改循环变量
  1. 通用问题：
  • 忘记包含必要头文件（如math.h）
  • 浮点数比较使用==
  • 复合语句忘记加花括号

六、综合练习

  2. 计算级数和：1! + 2! + 3! + … + 10!
  1. 输出100~999范围内的所有回文数
  1. 用牛顿迭代法求方程根

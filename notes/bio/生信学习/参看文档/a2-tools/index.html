附录二　工具速查

附录二　工具速查

⚠️ 本附录不列版本号。本书成稿于 2026 年，而下列工具版本迭代很快；
任何”当前版本”的说法都会在交付后迅速过期。使用前请以各项目官方文档为准。
本附录只回答”这个工具解决什么问题、在本书哪一章讲过”。

A 命令行与流式处理

工具 解决什么 对应章
awk 按列处理表格、字段提取、流式统计 ch34
sed 逐行替换、抽取 ch34
grep 模式筛选 ch34
sort / uniq 排序与去重计数 ch34
tr 字符替换 ch34
ssh 远程登录 ch34
git 脚本与文档的版本控制 ch34

B 序列与基因组文件

工具 解决什么 对应章
samtools BAM/SAM 读写、排序、索引、统计 ch34
bedtools 区间集合运算（并、交、差） ch34
tabix 大文件的随机访问索引 ch34
SQLite 结构化元数据的轻量存储与查询 ch34

C 序列分析

工具 解决什么 对应章
BLAST 数据库相似性搜索 ch06
FASTA（算法） 敏感度更高的数据库搜索 ch06
Needleman–Wunsch 全局比对 ch06、ch22
Smith–Waterman 局部比对 ch06、ch22
PAM / BLOSUM 打分矩阵 ch06、ch24

D 单细胞

工具 解决什么 对应章
scanpy 单细胞流程主控 ch46–ch49
anndata 单细胞数据容器（AnnData） ch46

ch49（API 参考）与 ch49（自动生成条目）是查阅材料，
不建议通读；用法先看 ch46 的工作流。

E Python 与 Biopython

工具 解决什么 对应章
Python 脚本语言基础 ch43
Biopython 序列、注释、结构、比对相关库 ch43
Biopython SeqIO 序列文件读写 ch43
Biopython SeqRecord / SeqFeature 序列与注释对象 ch43

F 机器学习

工具 解决什么 对应章
DeepChem 分子机器学习任务框架 ch51
SMILES 分子线性文本表示 ch53
图神经网络 分子图表示学习 ch53
自监督预训练 无标注数据上学习表示 ch53
分子对接 蛋白-配体结合构象预测 ch53

G 画图与文档

工具 解决什么 对应章
ggplot2 R 的图形系统 ch39
MyST 本书的构建工具链

H 关于版本的一句话

本书刻意不给版本号。理由不是偷懒，而是：在这些工具上，
“照着某个版本的文档做”本身就是可复现性的敌人。
第四编整本书讲的正是这件事——正确的做法是锁定你自己的环境，
而不是依赖一本书里的版本号。参见 ch46 关于环境锁定的说明。
